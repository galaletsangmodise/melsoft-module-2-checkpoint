## About the project

This project is a single JavaScript file that works through ten interview-style challenges on variables, data types, type conversion and type coercion. Each challenge is commented line by line, covering things like `var` vs `let` vs `const`, the quirks of `typeof`, why `0.1 + 0.2 !== 0.3`, and a code review and refactor of poorly written code. I learnt that JavaScript converts types silently, so I must be deliberate about types myself, especially with the `+` operator, which concatenates when a string is involved. I also learnt to convert form input explicitly with `Number()` and validate it with `Number.isNaN()`, and to use `const` by default for predictable code.

## How to run

Run with: `node galaletsang-modise-module2.js`
